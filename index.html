Same city, same night

No servers to set up, no ports to open. Everyone just needs the same version, and the game keeps itself up to date.

  1. Install Ember Bay

    Everyone downloads it from this page. It updates itself when there's a new version.

  2. One of you hosts

    Play with friends → Host. You get a 6-letter room code. Copy it to your group chat.

  3. Everyone else joins

    Play with friends → Join, type the code, and you appear next to the host.

  4. Find each other

    Friends show as green arrows on the map. Press F next to a friend's car to ride with them, T to chat.

First time installing?

Windows

It may say "Windows protected your PC" the first time, because Ember Bay is an indie game without a paid code-signing certificate. Click More info → Run anyway. It installs to your user folder and adds a desktop shortcut.

macOS

Open the .dmg and drag Ember Bay into Applications. The first time you open it, macOS will say it can't check it for malware (indie game, no paid Apple certificate). Click Done, then go to System Settings → Privacy & Security, scroll down and click Open Anyway. You only do this once; after that it opens normally and updates itself.

Linux

It's one file, EmberBay-Linux.AppImage. Right-click it → Properties → Allow executing as program (or chmod +x EmberBay-Linux.AppImage), then double-click it. If nothing opens on Ubuntu 22.04 or newer, install FUSE once: sudo apt install libfuse2t64 (on 22.04: libfuse2). It updates itself like the other versions.
